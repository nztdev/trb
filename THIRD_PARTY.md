# Third-party software

| Component | Version | Licence | Where |
|---|---|---|---|
| [three.js](https://threejs.org) | r128 | MIT | `vendor/three.min.js` (licence: `vendor/LICENSE-three.txt`) |
| City data (names, positions, populations) | all-the-cities 3.1.0, from [GeoNames](https://www.geonames.org) | CC BY 4.0 (data), ISC (package) | embedded in `index.html` as one compact string |
| [Bricolage Grotesque](https://github.com/ateliertriay/bricolage) (via Fontsource) | 400, 600 (latin) | SIL Open Font License 1.1 | `fonts/*.woff2` (licence: `fonts/OFL.txt`) |

Continent outlines come from [Natural Earth](https://www.naturalearthdata.com) (public domain) via the `world-atlas` package, rasterised into a small image embedded in `index.html`.

Everything else (the game, the planets, the sound, the icons) is generated by the code in this repository.
